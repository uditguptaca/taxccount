# United Arab Emirates: what was done with the independent review's findings (A1 to A11)

Corrected on 2026-11-12. "Structural" means the rule was made to agree with the item's own words; "fact" means an
official page was opened on that day and the sentence it rests on is quoted. Every fixed finding is held by
`tests/verify/review_ae.ts` (29 checks, fixed "today" 2026-11-11). Base pack `ae.ts` went from version 2026.11.2 to 2026.11.3.

## Things to know
- `ae_ct_np_year` is a choice whose answers are dates (the last day of each year), so the existing "counted from a date"
  rule can work out 31 March and report a deadline that has passed. A 2027 answer has to be added by hand in 2027.
- `ae_dmtt_register` uses a one-off date (30 November 2026). After that day the engine drops it from the row; the
  later variant keeps working.
- New items: `ae_dmtt_register_later` (base), `ae_x_adgm_gratuity`, `ae_x_adpf_pension` (research file). New
  questions: `ae_ct_np_year`, `ae_dmtt_first_late`. New sources: `vat_reg_svc`, `tax_penalties`, `ae_x_src_adgm_er_guide`.
